## 2. 边界条件 / 异常评估（我扮演模型的对抗测试，11 类响应）

| 6 | **特殊标记** `<\|TOOL_CAL…\|>`（真实 the text-model provider 实测怪癖） | ❌ JSON 解析失败 | ✅ 三重容错解析 | 此前真实 API 实测发现并修复 |

| 9 | **VLM 幻觉字段**（页面没有的"眼睛颜色/身高"） | ❌ 会学成自定义字段污染档案 | ✅ **页面锚定过滤**（标签必须出现在页面文本中） | 已修复 |
| 10 | **VLM 注入标签**（`<img onerror=…>`）/ 空值 / 超长条目 | ⚠️ 部分过滤 | ✅ 全部丢弃 | 已修复 |

其余边界（此前已测，均有回归）：PDF 超大文件/解压炸弹/畸形结构、坏 JSON 导入、导入错文件类型、多上下文并发写入、storage 损坏自愈、空文本/空页面、冲突字段（公司电话）、调试端口占用、浏览器 API 不可用降级、LLM 超时/非 2xx/坏响应。

**评估结论**：模型侧的"不可信输出"全部被收敛为三条安全路径——①采纳（正常）②截断（超长）③回退模板/样例（拒答/废话/解析失败）；VLM 结果必须"页面可见"才入库。**未发现新的未防护异常面。**

## 3. 优化方案（基于测试结果）

**本轮已实现（测试驱动）**：
1. ✅ First/Last Name 分栏识别与姓名自动拆分（含复姓）——真实网页最大缺口
2. ✅ 别名命中特异性加权——消除 `ethnicity`/`city` 类子串撞词
3. ✅ 模型输出净化（拒答/推脱/超短拒收、超长截断）——模型不可信输出的兜底
4. ✅ VLM 页面锚定过滤——防幻觉字段污染档案
5. ✅ 解析器标题判定长度护栏——正文含别名词不再被误判为标题

**后续优化（按优先级）**：
| 优先级 | 方案 | 目的 |
|---|---|---|
| P1 | 生成内容"事实一致性"校验：把生成文本中的数字/公司/职位与档案比对，编造则回退 | 防模型一本正经编造（现靠样例优先+净化已缓解） |
| P1 | 站点维度学习报表：按站点统计匹配/学习次数，导出站点别名词典 | 大规模投递后可量化"越用越准"效果 |
| P2 | 表格型网申页增强（51job/北森表格布局的行列标签、合并单元格） | 中文大型招聘站的表格式表单识别率 |
| P2 | 低置信度批量确认面板（一次审阅全部 review 档字段） | 提升人工确认效率 |
| P3 | VLM 页面核对改"逐字段问答"式（每字段一次小问答） | 进一步降幻觉（成本换准确） |
| P3 | Firefox/Safari 移植（MV3 + storage API 适配） | 扩大浏览器覆盖 |
