**待确认项均为正确行为**：复合字段（毕业院校及所学专业 / 现单位及岗位）进批量确认不乱填 ✓；"最近一次工作经验"等多义条目保守待确认 ✓；重复条目（多段工作经历）逐条列出 ✓。

**真实测试驱动的适配迭代**（从 0 匹配 → 19 个真实字段自动填出，共 5 轮修复）：
1. 通用占位符降噪（"请输入"不是标签）；
2. 容器标题启发（div/span 标题而非 `<label>`）；
3. name-less 自定义单选组件成组（aria-hidden Vue 组件 ws-radio）+ 包裹层点击；
4. **内嵌/双栏题干识别**（标签是紧邻空位的裸文本节点，需 8 层深度查找）——决定性突破；
5. 标签规范化（序号前缀"5."、内部空格"民 族"、"您的"前缀、提示尾巴"涉及个人敏感信息…"）。

| 边界 | 现状 |
|---|---|
