## 3. 边界与异常（重点）

### 3.1 本轮实现中发现并已修复的边界/异常（测试驱动）

| # | 边界/异常 | 表现 | 修复 |
|---|---|---|---|
| 1 | **助手 UI 污染扫描**：浮动面板自己的 select/checkbox 被当成表单字段（幻影字段 ×8） | 批量面板渲染后再扫描字段翻倍 | scan 排除 `#cv-panel/#cv-fab` 子树 |
| 2 | **容器选择器漏 td**：表格行整体文本当邻近文本 → 跨字段污染，"毕业院校"被判含冲突词"学历"误惩罚 | 表格页字段集体降档 | containerOf 增补 td/th（就近单元格语义） |
| 3 | **占位格重访覆盖配对**：rowspan 占位格解析到来源格后重复处理，用组标题（"教育及求职信息"）覆盖正确标签 | cellLabel 张冠李戴 | 配对循环只走真实格 + 同控件只配对一次 |
| 4 | 长标签含别名词被误判为解析标题（"GitHub 万星项目核心维护者"） | PDF 解析节结构错乱 | 标题判定长度护栏（≤14） |
| 5 | 模型拒答/推脱/超长/编造输出被直接采纳 | 生成内容质量不可控 | 净化（拒答/推脱/超短拒收、1500 字截断）+ 事实校验剥离编造句 |
| 6 | VLM 幻觉字段（"眼睛颜色"）污染档案 | 学习记录被垃圾字段污染 | 页面锚定过滤 + 逐字段问答双通道一致 |

### 3.2 当前实现的边界行为清单（设计取舍，均已在测试中断言）

| 边界 | 行为 | 定位 |
|---|---|---|
| 复合字段（毕业院校及所学专业） | 歧义 → 待确认（批量面板人工决定），**不猜测拆分** | 设计优先项：不误填 |
| 日期拆分控件（年/月/日 三个 select） | 唯一性保护 → 仅首项尝试，且选项语义无法精确对应日期 → 进待确认 | 见 §5 未完成 #1 |
| 同字段重复输入 | 唯一性保护：最高分 auto，其余 review 并标注 `duplicateOf` | 已测 |
| 忽略记忆粒度 | label 粒度全局生效（跨站点）；可一键恢复 | 已测 |
| 事实校验基准 | **以用户档案为准**：只剥离"档案+页面皆无来源"的数字/机构句；不质疑用户数据；校验自身异常→不剥离（宁多留不误删） | 已测 |
| 双通道不一致 | VLM 粗读与逐字段问答不一致 → 该项丢弃（宁缺勿错） | 已测 |
| 表格上限 | 网格 4000 格/200 行上限、descriptor 1000 上限 | 防冻结 |
| 非表格页面 | table-layout 返回 null，行为与增强前**逐字节一致**（零回归，145+111 全绿佐证） | 兼容性保证 |
