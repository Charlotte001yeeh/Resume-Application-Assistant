What this prototype demonstrates
1. The extension option can turn the floating ball on/off.
2. Default state shows only the ball — no panel, no text.
3. Clicking the ball reveals 4 function buttons arranged around it with a translucent background and no explanation text.
4. Clicking a function button opens the existing content view (display / explanation / actions) on an opaque white background.
