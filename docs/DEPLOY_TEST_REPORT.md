## 5. 测试中发现并修复的问题（持续修正记录）

| # | 问题 | 修复 |
|---|---|---|
| 1 | Chrome 153 移除 `--load-extension`（含 137 引入的绕过开关），扩展无法装载 | 改用 `--enable-unsafe-extension-debugging` + CDP `Extensions.loadUnpacked` 真实部署通道；测试与真实部署一致 |
| 2 | 精确标签命中 40 分低于 auto 阈值 45，大量字段只进"待确认" | 精确别名分提升至 48（与 SPEC 同步修订） |
| 3 | 短英文词（why/name/id）被"反向包含"误命中长别名（why→why do you want to join） | 反向包含要求"像词"：中文≥2字、拉丁≥4字符 |
| 4 | 裸别名"公司"使"为什么想加入我们公司"误匹配 currentCompany | 移除裸别名，保留"公司名称/所在公司"等 |
| 5 | 枚举同义词与目标值比对错位，select 选错项（本科≠master） | 重写为两段式：先解析目标枚举项（精确优先），再匹配页面选项；male/female 包含关系不再互扰 |
| 6 | JD 关键词被拆成二元碎片（"据可/微前"） | 短语级 n-gram 抽取 + 复现过滤 + 边界虚词过滤 |
| 7 | JD 区域识别取到整页文本，混入表单词噪声 | 取最小匹配节点（职位描述/任职要求区块） |
| 8 | "从本页学习"把 select 原始值（v0）写回档案、且覆盖信息更丰富的档案值 | 读取选项语义文本→枚举规范值回写；档案值更丰富时跳过回写 |
| 9 | 档案导入合并时丢失学习记录（别名/样例） | importJson 合并 learning（别名并集、样例去重） |
| 10 | 未见字段生成只看模板，未利用用户手写样例 | 生成优先级调整为：手写样例（fromSample，标注来源）＞ 相似字段多表达 ＞ 档板模板 |
| 11 | 仅有单档案，无法按公司维护多套简历表述；JSON 导入只能合并进当前 | 实现多套简历：索引 `cvProfileIndex` + 新建/克隆/切换/重命名/删除回落/按套导出；导入支持"合并到当前"与"新建为独立套"两种模式 |
| 12 | 无法导入已有简历 PDF（零依赖文本抽取 + 中文 CID 字体） | 实现 `core/pdf.js`（流扫描 + Flate 解压 + ToUnicode CMap + 文本算子）与 `core/resume-parse.js`（标签语义映射 + 未知字段新建 + 头部快取） |
| 13 | 解析器把正文行误判为节名（"…项目核心维护者"）；单行字段被后续行污染；同行「标签：内容」长标签漏判 | 节名关键词锚定行尾；非长文本字段只取首行；同行标签放宽到 16 字符 |
| 14 | **硬伤**：store 缓存旧档案，选项页编辑会整体回写、覆盖内容脚本（样例学习/回写）的新写入 → 数据丢失 | `load()` 每次读后端（不信任缓存）；回归测试：双上下文并发写入不丢数据 |
| 15 | PDF 无资源上限：超大文件冻结页面、Flate 解压炸弹可撑爆内存 | 20MB 输入上限、32MB 单流解压上限、2000 流上限、选项页文件大小前置校验；边界回归测试 3 项 |
| 16 | 测试管线固定调试端口：若被占用会连接到用户正在用的其他浏览器实例 | 端口随机避让 + 启动前探测占用即拒绝连接 |
| 17 | 持久化边界未覆盖"卸载扩展/清空配置/换机"丢失场景 | 增加完整备份（全量 bundle）/灾难恢复 + 自动备份到本地文件夹（File System Access + IndexedDB 句柄持久化 + 副本轮转），README 增加"什么会丢/不丢"对照表 |

| 19-23 | **真实网页语料 + 模型对抗测试发现**（详见 `docs/REAL-WEB-TEST-REPORT.md`）：First/Last Name 分栏误填全文；`ethnicity` 撞 `city` 子串误判；模型拒答/推脱输出被当作生成内容采纳；VLM 幻觉字段污染档案；正文含别名词被误判为解析标题 | 姓名自动拆分（含复姓）；别名特异性加权；生成输出净化（拒答/推脱/超短拒收+超长截断）；VLM 页面锚定过滤；解析标题长度护栏 |

## 6. 已知限制

1. 静态同义词典覆盖常见字段，极冷门字段走"待确认"通道（可一键采纳），不误填是设计优先项。
2. 日期选择器组件（第三方日历）依赖 input[type=date] 或原生赋值，纯自定义日历需人工点选。
3. 跨域 iframe 表单受浏览器隔离限制，仅在同源/可注入 frame 内生效（manifest 已开 all_frames）。
4. LLM 增强（可选）默认关闭；开启后发送的上下文仅为当前字段问答所需最小信息，失败自动回退离线模板。

## 7. 结论

单元 98/98、端到端 96/96 全部通过，真实 Chrome 窗口部署形态全流程验证并留有截图证据。**需求 1/2/3 全部达成（多套简历 + PDF/图片简历导入 + 可选 VLM 校对 + 三层数据备份保障），可交付使用。**

样例学习闭环（本次需求澄清的核心）已端到端验证：**扫描已填写页面 → 相似字段归并 + 未见字段建档 + 手写样例入库 → 新页面自动识别、生成复用你的表达**，插件随投递次数增加持续改进。
