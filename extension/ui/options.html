Resume Profile Manager 0

Your profile is stored locally in the browser (chrome.storage.local) and can be edited anytime; it powers semantic auto-fill on online application forms and resume checks.

How to Use

  1. Fill in / update key resume fields here (auto-saved).
  2. Open any job application page and click the CV button at the bottom right → "One-click Fill"; the plugin detects semantically matching fields and fills them in.
  3. Click "Resume Check": auto-generate summaries for unseen fields, suggest similar field phrasings, and optimize the content you already filled in.
  4. Click "Learn from This Page": write back what you typed on the page into your profile to keep it up to date.

Multiple Profiles (for different companies / scenarios)

Each profile is fully independent (its own fields, custom fields, and learning data): whichever profile is active is the one used for fill / check / sample learning. Useful for preparing different wording per company or role. When importing JSON you can choose "Merge into current" or "Create as a separate profile".
(Works with the "Import" button in the toolbar above; applies to PDF/image/JSON)

Data Safety & Backup (prevent data loss)

Resume data is stored in browser extension storage: closing the browser, restarting your PC, or clearing browsing data (cache/cookies) will NOT lose it; but uninstalling the extension, deleting the browser user profile, or reinstalling the OS / switching computers without migration will. Recommended: enable "Auto backup to local folder" — backups are saved in a folder you choose (independent of browser storage), survive extension removal, and can be restored in one click after reinstalling.
Auto backup: Off
